Wiederherstellung / Odzyskiwanie

Diese Seite löscht keine Browserdaten und keinen Lernfortschritt. Sichere deinen Fortschritt vor dem Update. Schließe danach alle Ansichten der App einschließlich dieser Seite und öffne die Startadresse erneut.

Ta strona nie usuwa danych przeglądarki ani postępów. Zapisz kopię postępów przed aktualizacją. Następnie zamknij wszystkie widoki aplikacji, także tę stronę, i ponownie otwórz adres startowy.


Bereit. / Gotowe.

Zur App / Wróć do aplikacji

Grenzen: Für das Herunterladen eines Updates ist Internet erforderlich. Die Seite muss unter derselben Website-Adresse erreichbar sein. Blockiert ein alter Worker auch diese Seite oder leitet der Server sie ungeeignet weiter, ist eine gesonderte Wiederherstellung nötig. Eine garantierte Umgehung aller alten Worker ist nicht möglich.

Ograniczenia: Pobranie aktualizacji wymaga internetu. Strona musi działać pod tym samym adresem witryny. Jeśli stary worker blokuje również tę stronę lub serwer przekierowuje ją nieprawidłowo, potrzebne jest osobne odzyskiwanie. Nie można zagwarantować obejścia każdego starego workera.
